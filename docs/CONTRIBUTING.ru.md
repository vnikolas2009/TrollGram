
# Участие в разработке TrollGram

Мы приветствуем исправления ошибок, предложения и новые функции.

Перед отправкой изменений ознакомьтесь с этими рекомендациями.

## Перед началом работы

- Проверьте существующие Issues и Pull Requests.
- Убедитесь, что ваше изменение относится к проекту.
- Если планируете крупное изменение, сначала обсудите его через Issue.

## Подготовка проекта

Клонируйте репозиторий вместе с подмодулями:

```bash
git clone --recursive https://github.com/vnikolas2009/TrollGram.git
cd TrollGram
git submodule update --init --recursive
```

Подготовьте окружение:

```bash
python3 build-system/setup_python.py
```

Инструкции по сборке находятся в [README](../README.md).

## Внесение изменений

Чтобы упростить проверку и поддержку кода:

- Старайтесь решать одну задачу за раз.
- Придерживайтесь существующего стиля кода.
- Не изменяйте файлы, не относящиеся к вашей задаче.
- Не добавляйте сгенерированные файлы без необходимости.
- Проверяйте изменения перед отправкой.

## Функции приватности

Изменения, связанные с приватностью, требуют особого внимания.

При отправке таких изменений укажите:

- Что делает функция.
- Влияет ли она на обработку сообщений или сетевые запросы.
- Какие у неё есть ограничения.
- Как вы проверяли её работу.

Не заявляйте, что клиентские функции обеспечивают полную анонимность.

## Python-плагины

Изменения системы плагинов должны сохранять совместимость
с существующей структурой.

Если вы меняете API плагинов, обязательно опишите изменения.
Не добавляйте лишние разрешения и доступ к пользовательским данным
без необходимости.

## Pull Requests

При создании Pull Request:

1. Опишите проблему или предлагаемую функцию.
2. Перечислите внесённые изменения.
3. При необходимости приложите скриншоты или логи.
4. Укажите, какие проверки вы выполнили.
5. Добавьте ссылки на связанные Issues.

Не объединяйте несколько несвязанных изменений в одном запросе.

## Сообщения коммитов

Используйте короткие и понятные сообщения.

Примеры:

```text
fix: correct plugin loading
feat: add privacy setting
docs: update installation instructions
refactor: simplify plugin manager
```

## Сообщение об ошибках

При создании Issue укажите:

- Версию iOS.
- Модель устройства.
- Версию TrollGram или commit.
- Шаги для воспроизведения ошибки.
- Ожидаемое и фактическое поведение.
- Логи или скриншоты, если они нужны.

Не публикуйте пароли, сертификаты, токены и личные сообщения.

## Проблемы безопасности

Не публикуйте подробности неисправленной уязвимости
в открытом Issue.

Сначала свяжитесь с сопровождающими проекта приватно.

## Лицензия

Отправляя изменения в проект, вы соглашаетесь с тем,
что они могут распространяться на условиях применимой лицензии проекта.
